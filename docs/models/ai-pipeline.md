# AI / ML Inference Pipeline

Location: `backend/inference/`

## Model Architecture

CouncilMed does not rely on a single monolithic model. It dynamically loads a "council" of models based on YAML manifests stored in the `model_registry/`.

For a "Brain MRI" study, the pipeline loads three specialized architectures:
1. **Classifier** (`classifier_v1.yaml`): A DenseNet121 architecture optimized for global feature extraction.
2. **Attention Model** (`attention_v1.yaml`): A ResNet50 architecture with a custom Spatial Attention block.
3. **Segmenter** (`segmenter_v1.yaml`): A U-Net based architecture adapted for classification via a global pooling head.

## The Pipeline

```text
Raw Input (JPEG/PNG/DICOM)
    ↓
Validation (Check size and format)
    ↓
Preprocessing (Torchvision)
    ↓
Model Execution (PyTorch)
    ↓
Logits → Softmax → Probabilities
    ↓
Grad-CAM Explainability
```

### 1. Preprocessing (`backend/inference/pipeline.py`)
Images are loaded via PIL. The `torchvision.transforms` module applies:
- `Resize(224, 224)`
- `CenterCrop(224)`
- `ToTensor()`
- `Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])`

These values match the ImageNet pre-training statistics used by the base PyTorch vision models.

### 2. Inference Execution (`backend/inference/executor.py`)
The pipeline runs the tensor through all loaded models. This happens sequentially in the current implementation, but is designed to be parallelizable on systems with sufficient VRAM.

### 3. Model Weights
Currently, the system uses structurally correct PyTorch graphs but with random initialization weights generated by `scripts/generate_weights.py`.
**Limitation**: To achieve clinical accuracy, these placeholder `.pth` files must be replaced with weights trained on medical datasets (e.g., BraTS, RSNA).

### 4. Explainability (Grad-CAM)
Location: `backend/explainability/gradcam.py`
To solve the "black box" problem, the system implements Gradient-weighted Class Activation Mapping (Grad-CAM). 
- It hooks into the final convolutional layer of each model.
- It calculates the gradient of the predicted class with respect to the feature map activations.
- It overlays this heatmap onto the original image, showing the clinician exactly *which pixels* influenced the AI's decision.
